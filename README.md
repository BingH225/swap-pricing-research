# 换电站智能定价研究知识包

面向研究 agent 的背景材料。包含两份知识文档、一份数据说明和一套数据示例。

| 内容 | 说明 |
|---|---|
| [01_业务知识.md](01_业务知识.md) | 价格构成、收入口径、调价节奏、线上策略结构与机制事实、当前评估方式、研究动机、术语 |
| [02_评估基准方案.md](02_评估基准方案.md) | 评估基准 v0（历史准实验五项任务及结论）与 v1（世界族、校准、有效性、考纲、判分口径、流程实例、与价值学习链路的衔接、实验设计、参考文献、开放问题） |
| [数据说明.md](数据说明.md) | 12 张逻辑表（10 张源表、2 张派生表）的粒度、用途、关系、口径陷阱，**完整字段表**（共 566 个字段），以及分布说明（归一化描述） |
| [数据示例/](数据示例/) | 每张表一个 CSV，列与数据说明中的完整字段一一对应，各含 3 行**虚构**示例 |

## 脱敏说明

- 不含任何真实数据记录，也不含代码。
- 不含公司、城市、站点、人员、内部系统与物理表名。表名为逻辑别名（如 `T_fact_hourly`）。
- 字段名保持原样；个别含品牌名、地域名的字段改为占位名，见数据说明 §1.3。
- 示例 CSV 中的数值全部为虚构，只用于说明格式和字段间的关系。
- 分布说明只使用比例、相对指数和取整后的量级，不出现金额、电量、价格、站点数等绝对值。
- 效果估计（半弹性等）为分析结论，取整后给出，只作量级与方向参考。

## 建议阅读顺序

1. 01 业务知识：建立机制概念。
2. 数据说明 §1–2：表关系与口径陷阱；§4：分布特征。
3. 02 评估基准方案：方法论；§14 为可认领的开放问题。
